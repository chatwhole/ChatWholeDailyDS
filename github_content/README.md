## ❓ Frequently Asked Questions (FAQ)

**Q: What is ChatWhole Learning Hub?**
A free open-source collection of 1,360 lesson indexes across 29 courses spanning data science, AI, engineering, programming and school mathematics — published on GitHub and linked to free lessons on [ChatWhole.com](https://chatwhole.com).

**Q: How do I find free machine learning tutorials?**
Start at the [Machine Learning course index](machine-learning/README.md) — 51 lessons from linear regression to transformers, MLOps and causal inference. All lessons are free; no signup required.

**Q: Which courses are best for beginners?**
[Statistics](https://chatwhole.com/learn/statistics/) → [Python](https://chatwhole.com/learn/python/) → [SQL](https://chatwhole.com/learn/sql/) → [Data Analytics](https://chatwhole.com/learn/data-analytics/). For programming foundations try [C](https://chatwhole.com/learn/c/), [C#](https://chatwhole.com/learn/csharp/), [R](https://chatwhole.com/learn/r/) or [React](https://chatwhole.com/learn/react/).

**Q: Are there industry-specific AI courses?**
Yes: [Healthcare AI](https://chatwhole.com/learn/healthcare-ai/), [Fintech](https://chatwhole.com/learn/fintech/), [Drone AI](https://chatwhole.com/learn/drone-ai/) and [Quantum Computing](https://chatwhole.com/learn/quantum-computing/) — 45-50 lessons each.

**Q: Does ChatWhole cover engineering subjects?**
Yes — nine 30-lesson engineering courses: [Mechanical](https://chatwhole.com/learn/mechanical-engineering/), [Electrical](https://chatwhole.com/learn/electrical-engineering/), [Power Electronics](https://chatwhole.com/learn/power-electronics/), [Control Systems](https://chatwhole.com/learn/control-systems/), [Electrical Machines](https://chatwhole.com/learn/electrical-machines/), [Embedded Systems](https://chatwhole.com/learn/embedded-systems/), [Renewable Energy](https://chatwhole.com/learn/renewable-energy-systems/), [Instrumentation](https://chatwhole.com/learn/electrical-instrumentation/) and [High Voltage](https://chatwhole.com/learn/high-voltage-engineering/).

**Q: Is there CBSE or school-level content?**
Yes — [CBSE Class 11 Mathematics](https://chatwhole.com/learn/cbse-class11/) with 81 lessons covering trigonometry, algebra, coordinate geometry, calculus, probability and statistics.

**Q: Is everything free?**
Yes — all 1,360 lessons are free to read on ChatWhole.com and free to clone from GitHub. No account or signup is required.

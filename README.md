## FAQ

### What is the ChatWhole Learning Hub?
A free, open collection of structured tutorials for data science, machine learning, AI, engineering, programming and school-level mathematics — hosted on GitHub and published on ChatWhole.com.

### How many lessons are available?
1,360 lessons across 29 indexed courses, plus 17 long-form course guides in this repository. Every lesson URL was verified as live (HTTP 200) when the index was built in October 2026.

### Which course should a complete beginner start with?
Start with [Statistics](https://chatwhole.com/learn/statistics/), then [Python](https://chatwhole.com/learn/python/), then [SQL](https://chatwhole.com/learn/sql/). After that pick the [Data Analytics](https://chatwhole.com/learn/data-analytics/) path or the [Machine Learning](https://chatwhole.com/learn/machine-learning/) path.

### Is there a free machine learning course?
Yes — a 51-lesson machine learning course covering linear regression, decision trees, random forest, XGBoost, neural networks, transformers, MLOps, A/B testing and causal inference. Start at [Lesson 1](https://chatwhole.com/learn/machine-learning/01-what-is-machine-learning/).

### Do you have Apache Kafka, Snowflake and PySpark tutorials?
Yes: [Apache Kafka (15 lessons)](https://chatwhole.com/learn/kafka/), [Snowflake (50 lessons)](https://chatwhole.com/learn/snowflake/) and [PySpark (40 lessons)](https://chatwhole.com/learn/pyspark/), each with a full lesson index in this repository.

### What generative AI and LLM content is included?
[Generative AI (106 lessons)](https://chatwhole.com/learn/generative-ai/) covers diffusion models, transformers, RAG and agents; [LLM (105 lessons)](https://chatwhole.com/learn/llm/) covers tokenization, fine-tuning, LoRA, alignment and inference optimization; [AI Agents (55 lessons)](https://chatwhole.com/learn/ai-agents/) covers tool use, memory and multi-agent systems.

### Do you have industry-specific AI courses?
Yes: [Healthcare AI (45 lessons)](https://chatwhole.com/learn/healthcare-ai/) for medical imaging and clinical NLP; [Fintech (50 lessons)](https://chatwhole.com/learn/fintech/) for trading, risk and payments; [Drone AI (50 lessons)](https://chatwhole.com/learn/drone-ai/) for autonomous navigation and computer vision; [Quantum Computing (50 lessons)](https://chatwhole.com/learn/quantum-computing/) for quantum algorithms and QML.

### Do you cover engineering subjects?
Yes — 8 engineering courses: [Electrical Engineering](https://chatwhole.com/learn/electrical-engineering/), [Mechanical Engineering](https://chatwhole.com/learn/mechanical-engineering/), [Power Electronics](https://chatwhole.com/learn/power-electronics/), [Control Systems](https://chatwhole.com/learn/control-systems/), [Electrical Machines](https://chatwhole.com/learn/electrical-machines/), [Embedded Systems](https://chatwhole.com/learn/embedded-systems/), [Renewable Energy Systems](https://chatwhole.com/learn/renewable-energy-systems/), [Electrical Instrumentation](https://chatwhole.com/learn/electrical-instrumentation/) and [High Voltage Engineering](https://chatwhole.com/learn/high-voltage-engineering/) — 30 lessons each.

### What programming languages are covered?
[C](https://chatwhole.com/learn/c/), [C#](https://chatwhole.com/learn/csharp/), [Python](https://chatwhole.com/learn/python/), [R](https://chatwhole.com/learn/r/) and [React](https://chatwhole.com/learn/react/) — each a 30-50 lesson course with full indexes.

### Is there content for school students?
Yes — [CBSE Class 11 Mathematics (81 lessons)](https://chatwhole.com/learn/cbse-class11/) covering trigonometry, algebra, coordinate geometry, calculus, probability and statistics, aligned to the NCERT syllabus.

### Are the tutorials free? Do I need an account?
Yes, all lessons are free to read on ChatWhole.com and free to clone from GitHub — no account or signup is required.
